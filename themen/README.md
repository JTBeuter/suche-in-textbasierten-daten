# Themenbereiche

Die praktische Arbeit ist in fünf Themenbereiche gegliedert. Alle Bereiche verwenden dieselbe Textaufbereitung, Dokumentkennungen und Testdaten, damit die Suchverfahren vergleichbar bleiben.

| Bereich | Aufgabe | Darstellung in der Arbeit |
|---|---|---|

Jeder Bereich enthält `src/` für die Implementierung, `tests/` für fachliche Prüfungen und `experimente/` für eigene Versuche. Gemeinsame Bausteine liegen in [gemeinsam/](../gemeinsam/), die Datengrundlage in [daten/](../daten/) und Messergebnisse in [ergebnisse/](../ergebnisse/).
